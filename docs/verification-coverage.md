## Summary

- **Buyer Only**: exists only in Buyer Re-verification — items about the buyer's own preparation, negotiation, or transfer paperwork that have no Seller-side equivalent by nature.
- **Not Applicable**: not an inspection item (meta commentary about the original guide) or fully superseded by a named architecture decision, with no residual gap.
